# WAF (Security) Rules for Music Label Protection

This document contains specialized WAF rules designed to block music label scanners, reporting bots, and copyright enforcement agencies.

## 1. Cloudflare WAF Custom Rule (Expression)

Copy and paste the following expression into a **Cloudflare WAF Custom Rule** (Security > WAF > Custom Rules).

**Action:** Block
**Expression:**

```sql
(
  (
    (http.user_agent contains "MarkMonitor") or 
    (http.user_agent contains "OpSec") or 
    (http.user_agent contains "Corsearch") or 
    (http.user_agent contains "Digimarc") or 
    (http.user_agent contains "AudioLock") or 
    (http.user_agent contains "Red Points") or 
    (http.user_agent contains "Link-Busters") or 
    (http.user_agent contains "MUSO") or 
    (http.user_agent contains "AiPlex") or 
    (http.user_agent contains "WebSiren") or 
    (http.user_agent contains "CopyTrack") or 
    (http.user_agent contains "PicRights") or 
    (http.user_agent contains "LeakID") or 
    (http.user_agent contains "Entura") or 
    (http.user_agent contains "Marketly") or 
    (http.user_agent contains "GrayZone") or 
    (http.user_agent contains "Rivendell") or 
    (http.user_agent contains "IFPI") or 
    (http.user_agent contains "RIAA") or 
    (http.user_agent contains "Copyright") or 
    (http.user_agent contains "DMCA") or 
    (http.user_agent contains "Legal") or 
    (http.user_agent contains "Enforcement") or
    (ip.src.asnum in {55195 6461})
  )
  and (not cf.client.bot)
)
```

## 2. Block Known Bot ASNs (Autonomous System Numbers)

Blocking the networks used by these agencies is highly effective. Add these to your IP Access Rules or as part of the WAF rule above.

| Agency/Network | ASN | Description |
| --- | --- | --- |
| MarkMonitor | 55195 | Major copyright enforcement agency |
| Zayo (Used by MarkMonitor) | 6461 | Network backbone often used by scrapers |
| Amazon / AWS | 16509 | Optional: Block if no legitimate users from AWS |
| Google Cloud | 15169 | Optional: Block if no legitimate users from GCP |
| Microsoft Azure | 8075 | Optional: Block if no legitimate users from Azure |

## 3. Recommended Settings

1. **Bot Fight Mode:** Enable "Bot Fight Mode" in Cloudflare (Security > Bots). This uses behavioral analysis to challenge headless browsers.
2. **Browser Integrity Check:** Ensure this is ON (Security > Settings). It blocks visitors with headers that are typical of malicious bots.
3. **Hotlink Protection:** Enable in Scrape Shield to prevent labels from using your images directly in their reports.

### 4. Reporting & Monitoring

To see who is being blocked:

1. Go to **Security > Events**.
2. Filter by the Rule Name you created.
3. Examine the User-Agents and IP locations.
